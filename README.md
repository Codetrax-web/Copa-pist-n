🏆 Copa Pistón

"Algunos trofeos representan más que una victoria." Este proyecto fue creado como una experiencia visual inspirada en la legendaria Copa Pistón, símbolo de esfuerzo, perseverancia y pasión por alcanzar los sueños. Cada detalle, animación y efecto busca transmitir la emoción de cruzar la meta después de una gran carrera, celebrando el valor de nunca rendirse y seguir acelerando hacia nuevas metas.
